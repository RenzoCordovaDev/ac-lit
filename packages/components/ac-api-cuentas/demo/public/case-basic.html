Simula el ciclo de vida de cuentas bancarias, desde la apertura hasta el cierre.

Propiedades

  • version String, por defecto 'v1'

    Versión de los mocks / del servicio simulado que se consume. No cambia el comportamiento por sí sola — es informativa, para simular múltiples versiones de API en una demo o integración.

  • timeout Number, por defecto 3000

    Milisegundos de latencia simulada antes de resolver o rechazar cada llamada. Se aplica por instancia: todas las llamadas de esa instancia esperan el mismo tiempo configurado.

  • simulateError Boolean, por defecto false

    Si es true, fuerza que toda llamada posterior falle (dispara el evento de error correspondiente) sin tocar los datos mock — pensado para probar el manejo de errores del consumidor. Se puede alternar en caliente.

Métodos públicos

  • listarTiposCuenta()

    Devuelve los tipos de cuenta disponibles.

    Dispara: ac-api-cuentas-types-success / ac-api-cuentas-types-error
  • listarCuentas(queryParams = {})

    Lista las cuentas. estado y tipoId filtran los resultados, sortBy y sortDir los ordenan, y pagination y page los paginan.

    Dispara: ac-api-cuentas-list-success / ac-api-cuentas-list-error
  • abrirCuenta(tipoId, alias)

    Crea una cuenta activa con la moneda del tipo y la fecha actual en UTC. Falla si el tipo no existe.

    Dispara: ac-api-cuentas-open-success / ac-api-cuentas-open-error
  • actualizarAlias(cuentaId, alias)

    Cambia el alias de una cuenta activa o bloqueada.

    Dispara: ac-api-cuentas-rename-success / ac-api-cuentas-rename-error
  • bloquearCuenta(cuentaId, motivo)

    Bloquea una cuenta activa y guarda el motivo en motivoBloqueo.

    Dispara: ac-api-cuentas-block-success / ac-api-cuentas-block-error
  • cerrarCuenta(cuentaId)

    Cierra una cuenta activa o bloqueada y la conserva en el listado.

    Dispara: ac-api-cuentas-close-success / ac-api-cuentas-close-error
