Simula productos de inversión (depósitos a plazo y fondos mutuos): listado, simulación de rentabilidad, suscripción, listado de inversiones y rescate.

Propiedades

  • version String, por defecto 'v1'

    Versión de los mocks / del servicio simulado que se consume. No cambia el comportamiento por sí sola — es informativa, para simular múltiples versiones de API en una demo o integración.

  • timeout Number, por defecto 3000

    Milisegundos de latencia simulada antes de resolver o rechazar cada llamada. Se aplica por instancia: todas las llamadas de esa instancia esperan el mismo tiempo configurado.

  • simulateError Boolean, por defecto false

    Si es true, fuerza que toda llamada posterior falle (dispara el evento de error correspondiente) sin tocar los datos mock — pensado para probar el manejo de errores del consumidor. Se puede alternar en caliente.

Métodos públicos

  • listarProductos(queryParams = {})

    Lista los productos de inversión. queryParams: tipo, sortBy/sortDir, pagination/page.

    Dispara: ac-api-inversiones-products-success / ac-api-inversiones-products-error
  • simularRentabilidad(productoId, monto, plazoDias)

    Calcula la rentabilidad estimada proporcional al plazo y el monto final, sin crear una inversión; falla si el producto no existe o el monto es menor al mínimo.

    Dispara: ac-api-inversiones-simulate-success / ac-api-inversiones-simulate-error
  • suscribirInversion(productoId, monto)

    Crea una inversión activa en el producto, con inicio hoy y vencimiento según su plazo (null en fondos mutuos sin plazo); falla si el monto es menor al mínimo del producto.

    Dispara: ac-api-inversiones-subscribe-success / ac-api-inversiones-subscribe-error
  • listarInversiones(queryParams = {})

    Lista las inversiones. queryParams: estado, productoId, sortBy/sortDir, pagination/page.

    Dispara: ac-api-inversiones-list-success / ac-api-inversiones-list-error
  • rescatarInversion(inversionId)

    Rescata una inversión: devuelve principal más rentabilidad proporcional al tiempo transcurrido desde su inicio, y la marca como rescatada. Falla si no existe o ya fue rescatada.

    Dispara: ac-api-inversiones-redeem-success / ac-api-inversiones-redeem-error

Eventos

ac-api-inversiones-products-success, ac-api-inversiones-products-error, ac-api-inversiones-simulate-success, ac-api-inversiones-simulate-error, ac-api-inversiones-subscribe-success, ac-api-inversiones-subscribe-error, ac-api-inversiones-list-success, ac-api-inversiones-list-error, ac-api-inversiones-redeem-success, ac-api-inversiones-redeem-error
