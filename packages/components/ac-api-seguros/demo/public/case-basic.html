Simula el catálogo de seguros, cotizaciones, contrataciones y cancelaciones de pólizas.

Propiedades

  • version String, por defecto 'v1'

    Versión de los mocks / del servicio simulado que se consume. No cambia el comportamiento por sí sola — es informativa, para simular múltiples versiones de API en una demo o integración.

  • timeout Number, por defecto 3000

    Milisegundos de latencia simulada antes de resolver o rechazar cada llamada. Se aplica por instancia: todas las llamadas de esa instancia esperan el mismo tiempo configurado.

  • simulateError Boolean, por defecto false

    Si es true, fuerza que toda llamada posterior falle (dispara el evento de error correspondiente) sin tocar los datos mock — pensado para probar el manejo de errores del consumidor. Se puede alternar en caliente.

Métodos públicos

  • listarProductos(queryParams = {})

    Lista el catálogo de seguros. queryParams: tipo, sortBy/sortDir, pagination/page.

    Dispara: ac-api-seguros-products-success / ac-api-seguros-products-error
  • cotizar(productoId, datos)

    Estima la prima mensual del producto: primaMensual multiplicado por datos.factorRiesgo (por defecto 1). Falla si el producto no existe.

    Dispara: ac-api-seguros-quote-success / ac-api-seguros-quote-error
  • contratarSeguro(productoId, datos)

    Crea una póliza nueva en estado vigente, con número autogenerado (POL-00XX) y vigencia de un año desde hoy. Falla si el producto no existe.

    Dispara: ac-api-seguros-subscribe-success / ac-api-seguros-subscribe-error
  • listarPolizas(queryParams = {})

    Lista las pólizas de la instancia. queryParams: estado, productoId, sortBy/sortDir, pagination/page.

    Dispara: ac-api-seguros-policies-success / ac-api-seguros-policies-error
  • cancelarPoliza(polizaId, motivo)

    Cambia el estado de la póliza a cancelada y guarda el motivo. Falla si la póliza no existe o ya está cancelada.

    Dispara: ac-api-seguros-cancel-success / ac-api-seguros-cancel-error

Eventos

ac-api-seguros-products-success, ac-api-seguros-products-error, ac-api-seguros-quote-success, ac-api-seguros-quote-error, ac-api-seguros-subscribe-success, ac-api-seguros-subscribe-error, ac-api-seguros-policies-success, ac-api-seguros-policies-error, ac-api-seguros-cancel-success, ac-api-seguros-cancel-error
