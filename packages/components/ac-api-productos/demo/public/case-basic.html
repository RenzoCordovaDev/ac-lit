Simula el consumo de una API de productos, con catálogo y detalle extendido.

Propiedades

  • version String, por defecto 'v1'

    Versión de los mocks / del servicio simulado que se consume. No cambia el comportamiento por sí sola — es informativa, para simular múltiples versiones de API en una demo o integración.

  • timeout Number, por defecto 3000

    Milisegundos de latencia simulada antes de resolver o rechazar cada llamada. Se aplica por instancia: todas las llamadas de esa instancia esperan el mismo tiempo configurado.

  • simulateError Boolean, por defecto false

    Si es true, fuerza que toda llamada posterior falle (dispara el evento de error correspondiente) sin tocar los datos mock — pensado para probar el manejo de errores del consumidor. Se puede alternar en caliente.

Métodos públicos

  • obtenerProducto(id, queryParams = {})

    Obtiene un producto por id. queryParams.fields proyecta solo esos campos.

    Dispara: ac-api-productos-get-product-success / ac-api-productos-get-product-error
  • listarProductos(queryParams = {})

    Lista productos. queryParams: category, status (active/inactive), sortBy/sortDir, pagination/page, fields.

    Dispara: ac-api-productos-list-success / ac-api-productos-list-error
  • buscarProductos(texto, queryParams = {})

    Busca por nombre (coincidencia parcial). Admite el mismo queryParams que listarProductos.

    Dispara: ac-api-productos-search-success / ac-api-productos-search-error
  • obtenerDetalleProducto(id)

    Detalle extendido: agrega especificaciones e inventario (datos anidados) al producto.

    Dispara: ac-api-productos-get-detail-success / ac-api-productos-get-detail-error
  • registrarProducto(objetoProducto)

    Crea un producto nuevo. nombre y precio son obligatorios; categoria/stock son opcionales.

    Dispara: ac-api-productos-register-success / ac-api-productos-register-error
  • actualizarProducto(id, cambios = {})

    Mezcla cambios sobre el producto existente (el id no se puede sobrescribir).

    Dispara: ac-api-productos-update-success / ac-api-productos-update-error
  • eliminarProducto(id)

    Elimina un producto del mock por id.

    Dispara: ac-api-productos-delete-success / ac-api-productos-delete-error
