Simula el consumo de una API de direcciones de envío, con dirección predeterminada.

Propiedades

  • version String, por defecto 'v1'

    Versión de los mocks / del servicio simulado que se consume. No cambia el comportamiento por sí sola — es informativa, para simular múltiples versiones de API en una demo o integración.

  • timeout Number, por defecto 3000

    Milisegundos de latencia simulada antes de resolver o rechazar cada llamada. Se aplica por instancia: todas las llamadas de esa instancia esperan el mismo tiempo configurado.

  • simulateError Boolean, por defecto false

    Si es true, fuerza que toda llamada posterior falle (dispara el evento de error correspondiente) sin tocar los datos mock — pensado para probar el manejo de errores del consumidor. Se puede alternar en caliente.

Métodos públicos

  • listarDirecciones(queryParams = {})

    Lista direcciones. queryParams: sortBy/sortDir, pagination/page, fields.

    Dispara: ac-api-direcciones-list-success / ac-api-direcciones-list-error
  • obtenerDireccion(id)

    Obtiene una dirección por id.

    Dispara: ac-api-direcciones-get-success / ac-api-direcciones-get-error
  • agregarDireccion(objetoDireccion)

    linea1 y ciudad son obligatorios. La primera dirección que se agrega queda como predeterminada.

    Dispara: ac-api-direcciones-add-success / ac-api-direcciones-add-error
  • actualizarDireccion(id, cambios = {})

    Mezcla cambios sobre la dirección existente (el id no se puede sobrescribir).

    Dispara: ac-api-direcciones-update-success / ac-api-direcciones-update-error
  • eliminarDireccion(id)

    Elimina una dirección; si era la predeterminada y queda alguna otra, promueve la primera que quede.

    Dispara: ac-api-direcciones-delete-success / ac-api-direcciones-delete-error
  • marcarPredeterminada(id)

    Marca una dirección como predeterminada; desmarca cualquier otra.

    Dispara: ac-api-direcciones-mark-default-success / ac-api-direcciones-mark-default-error
