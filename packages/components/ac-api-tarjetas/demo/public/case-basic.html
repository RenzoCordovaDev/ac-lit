Simula la gestión de tarjetas de débito y crédito: listado, solicitud, bloqueo, desbloqueo, cambio de PIN y consulta de línea disponible.

Propiedades

  • version String, por defecto 'v1'

    Versión de los mocks / del servicio simulado que se consume. No cambia el comportamiento por sí sola — es informativa, para simular múltiples versiones de API en una demo o integración.

  • timeout Number, por defecto 3000

    Milisegundos de latencia simulada antes de resolver o rechazar cada llamada. Se aplica por instancia: todas las llamadas de esa instancia esperan el mismo tiempo configurado.

  • simulateError Boolean, por defecto false

    Si es true, fuerza que toda llamada posterior falle (dispara el evento de error correspondiente) sin tocar los datos mock — pensado para probar el manejo de errores del consumidor. Se puede alternar en caliente.

Métodos públicos

  • listarTarjetas(queryParams = {})

    Lista las tarjetas del mock. queryParams: estado, tipo, sortBy/sortDir, pagination/page.

    Dispara: ac-api-tarjetas-list-success / ac-api-tarjetas-list-error
  • solicitarTarjeta(cuentaId, tipo)

    Crea una tarjeta activa para la cuenta indicada. tipo debe ser debito o credito.

    Dispara: ac-api-tarjetas-request-success / ac-api-tarjetas-request-error
  • bloquearTarjeta(tarjetaId, motivo)

    Bloquea una tarjeta activa; falla si no existe o ya está bloqueada.

    Dispara: ac-api-tarjetas-block-success / ac-api-tarjetas-block-error
  • desbloquearTarjeta(tarjetaId)

    Reactiva una tarjeta bloqueada; falla si no existe o no está bloqueada.

    Dispara: ac-api-tarjetas-unblock-success / ac-api-tarjetas-unblock-error
  • cambiarPin(tarjetaId, pinActual, pinNuevo)

    Valida el PIN actual contra el PIN simulado fijo y confirma el cambio; falla si la tarjeta no existe o el PIN actual no coincide.

    Dispara: ac-api-tarjetas-pin-success / ac-api-tarjetas-pin-error
  • consultarLineaDisponible(tarjetaId)

    Devuelve la línea de crédito y el disponible de una tarjeta de crédito; falla si la tarjeta no existe o es de débito.

    Dispara: ac-api-tarjetas-credit-line-success / ac-api-tarjetas-credit-line-error
