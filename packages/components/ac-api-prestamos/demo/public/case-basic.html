Simula productos de préstamo, simulación de cuotas, solicitudes, pagos de cuotas y cronograma.

Propiedades

  • version String, por defecto 'v1'

    Versión de los mocks / del servicio simulado que se consume. No cambia el comportamiento por sí sola — es informativa, para simular múltiples versiones de API en una demo o integración.

  • timeout Number, por defecto 3000

    Milisegundos de latencia simulada antes de resolver o rechazar cada llamada. Se aplica por instancia: todas las llamadas de esa instancia esperan el mismo tiempo configurado.

  • simulateError Boolean, por defecto false

    Si es true, fuerza que toda llamada posterior falle (dispara el evento de error correspondiente) sin tocar los datos mock — pensado para probar el manejo de errores del consumidor. Se puede alternar en caliente.

Métodos públicos

  • listarProductos(queryParams = {})

    Lista los productos de préstamo del mock. queryParams: sortBy/sortDir, pagination/page.

    Dispara: ac-api-prestamos-products-success / ac-api-prestamos-products-error
  • simularPrestamo(productoId, monto, plazoMeses)

    Calcula una cuota estimada con interés simple sobre la tasa anual del producto. Falla si el producto no existe, o si el monto o el plazo superan el máximo del producto.

    Dispara: ac-api-prestamos-simulate-success / ac-api-prestamos-simulate-error
  • solicitarPrestamo(productoId, monto, plazoMeses)

    Valida igual que simularPrestamo y crea un préstamo nuevo en estado activo, sin cuotas pagadas.

    Dispara: ac-api-prestamos-request-success / ac-api-prestamos-request-error
  • listarPrestamos(queryParams = {})

    Lista los préstamos. queryParams: estado, productoId, sortBy/sortDir, pagination/page.

    Dispara: ac-api-prestamos-list-success / ac-api-prestamos-list-error
  • pagarCuota(prestamoId)

    Suma una cuota pagada al préstamo; al pagar la última, su estado pasa a pagado. Falla si el préstamo no existe o no tiene cuotas pendientes.

    Dispara: ac-api-prestamos-pay-success / ac-api-prestamos-pay-error
  • obtenerCronograma(prestamoId)

    Devuelve un array de cuotas {numero, fecha, monto, estado} con fechas mensuales a partir de proximoPago. Falla si el préstamo no existe.

    Dispara: ac-api-prestamos-schedule-success / ac-api-prestamos-schedule-error
