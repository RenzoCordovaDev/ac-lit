Simula el consumo de una API de métodos de pago: listar, agregar, eliminar y procesar un pago.

Propiedades

  • version String, por defecto 'v1'

    Versión de los mocks / del servicio simulado que se consume. No cambia el comportamiento por sí sola — es informativa, para simular múltiples versiones de API en una demo o integración.

  • timeout Number, por defecto 3000

    Milisegundos de latencia simulada antes de resolver o rechazar cada llamada. Se aplica por instancia: todas las llamadas de esa instancia esperan el mismo tiempo configurado.

  • simulateError Boolean, por defecto false

    Si es true, fuerza que toda llamada posterior falle (dispara el evento de error correspondiente) sin tocar los datos mock — pensado para probar el manejo de errores del consumidor. Se puede alternar en caliente.

Métodos públicos

  • listarMetodosPago(queryParams = {})

    Lista métodos de pago guardados (sin exponer el número completo). queryParams: sortBy/sortDir, pagination/page, fields.

    Dispara: ac-api-pagos-list-success / ac-api-pagos-list-error
  • agregarMetodoPago(objetoMetodo)

    marca y numero son obligatorios; el número se enmascara en toda respuesta (solo se guardan los últimos 4 dígitos como ultimosDigitos).

    Dispara: ac-api-pagos-add-success / ac-api-pagos-add-error
  • eliminarMetodoPago(id)

    Elimina un método de pago por id.

    Dispara: ac-api-pagos-delete-success / ac-api-pagos-delete-error
  • marcarMetodoPredeterminado(id)

    Marca un método de pago como predeterminado; desmarca cualquier otro.

    Dispara: ac-api-pagos-mark-default-success / ac-api-pagos-mark-default-error
  • procesarPago(monto, metodoId)

    Procesa un pago con un método existente; falla si monto no es mayor a 0 o el método no existe.

    Dispara: ac-api-pagos-process-success / ac-api-pagos-process-error

Eventos

ac-api-pagos-list-success, ac-api-pagos-list-error, ac-api-pagos-add-success, ac-api-pagos-add-error, ac-api-pagos-delete-success, ac-api-pagos-delete-error, ac-api-pagos-mark-default-success, ac-api-pagos-mark-default-error, ac-api-pagos-process-success, ac-api-pagos-process-error
