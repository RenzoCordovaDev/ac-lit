Simula saldo, historial, compras, transferencias, depósitos y retiros.

Propiedades

  • version String, por defecto 'v1'

    Versión de los mocks / del servicio simulado que se consume. No cambia el comportamiento por sí sola — es informativa, para simular múltiples versiones de API en una demo o integración.

  • timeout Number, por defecto 3000

    Milisegundos de latencia simulada antes de resolver o rechazar cada llamada. Se aplica por instancia: todas las llamadas de esa instancia esperan el mismo tiempo configurado.

  • simulateError Boolean, por defecto false

    Si es true, fuerza que toda llamada posterior falle (dispara el evento de error correspondiente) sin tocar los datos mock — pensado para probar el manejo de errores del consumidor. Se puede alternar en caliente.

Métodos públicos

  • consultarSaldo(cuentaId)

    Devuelve el saldo actual de una cuenta del mock.

    Dispara: ac-api-operaciones-balance-success / ac-api-operaciones-balance-error
  • obtenerHistorial(cuentaId, queryParams = {})

    Lista los movimientos de una cuenta. queryParams: tipo, sortBy/sortDir, pagination/page.

    Dispara: ac-api-operaciones-history-success / ac-api-operaciones-history-error
  • comprar(productoId, cantidad = 1)

    Debita la cuenta principal (id 1) según un mock interno de precios; falla si no hay saldo suficiente.

    Dispara: ac-api-operaciones-buy-success / ac-api-operaciones-buy-error
  • transferir(cuentaOrigenId, cuentaDestinoId, monto)

    Mueve dinero entre dos cuentas del mock; falla si la cuenta origen no tiene saldo suficiente.

    Dispara: ac-api-operaciones-transfer-success / ac-api-operaciones-transfer-error
  • depositar(cuentaId, monto)

    Suma monto al saldo de la cuenta.

    Dispara: ac-api-operaciones-deposit-success / ac-api-operaciones-deposit-error
  • retirar(cuentaId, monto)

    Resta monto al saldo de la cuenta; falla si no hay saldo suficiente.

    Dispara: ac-api-operaciones-withdraw-success / ac-api-operaciones-withdraw-error
