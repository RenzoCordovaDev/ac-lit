Simula un carrito de compras: agregar, quitar, actualizar cantidad y ver el resumen.

Propiedades

  • version String, por defecto 'v1'

    Versión de los mocks / del servicio simulado que se consume. No cambia el comportamiento por sí sola — es informativa, para simular múltiples versiones de API en una demo o integración.

  • timeout Number, por defecto 3000

    Milisegundos de latencia simulada antes de resolver o rechazar cada llamada. Se aplica por instancia: todas las llamadas de esa instancia esperan el mismo tiempo configurado.

  • simulateError Boolean, por defecto false

    Si es true, fuerza que toda llamada posterior falle (dispara el evento de error correspondiente) sin tocar los datos mock — pensado para probar el manejo de errores del consumidor. Se puede alternar en caliente.

Métodos públicos

  • agregarItem(item)

    Agrega { productoId, nombre, precio, cantidad? }; si el producto ya está en el carrito, suma la cantidad.

    Dispara: ac-api-carrito-add-success / ac-api-carrito-add-error
  • quitarItem(productoId)

    Quita un ítem del carrito por productoId; falla si no está en el carrito.

    Dispara: ac-api-carrito-remove-success / ac-api-carrito-remove-error
  • listarItems(queryParams = {})

    Lista los ítems del carrito. queryParams: sortBy/sortDir, pagination/page, fields.

    Dispara: ac-api-carrito-list-success / ac-api-carrito-list-error
  • actualizarCantidad(productoId, cantidad)

    Cambia la cantidad de un ítem existente; falla si cantidad no es mayor a 0.

    Dispara: ac-api-carrito-update-quantity-success / ac-api-carrito-update-quantity-error
  • vaciarCarrito()

    Vacía el carrito por completo.

    Dispara: ac-api-carrito-clear-success / ac-api-carrito-clear-error
  • obtenerResumen()

    Devuelve { items, subtotal, impuestos, total } (impuestos al 18% fijo sobre el subtotal).

    Dispara: ac-api-carrito-summary-success / ac-api-carrito-summary-error

Eventos

ac-api-carrito-add-success, ac-api-carrito-add-error, ac-api-carrito-remove-success, ac-api-carrito-remove-error, ac-api-carrito-list-success, ac-api-carrito-list-error, ac-api-carrito-update-quantity-success, ac-api-carrito-update-quantity-error, ac-api-carrito-clear-success, ac-api-carrito-clear-error, ac-api-carrito-summary-success, ac-api-carrito-summary-error
