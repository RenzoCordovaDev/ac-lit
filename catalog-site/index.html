Lit v3 Web Components para crear sin límites

Comandos de FrontSpark

terminal — aclit

$ npm install -g @ac-base/cli

$ aclit component:create ac-mi-componente

# Componente creado en ./ac-mi-componente

$ aclit component:serve

# levanta la demo con Vite en http://localhost:5173

$ aclit component:build

# compila el componente a ./dist

$ aclit help

# lista todos los comandos disponibles

    Framework de formación frontend

    Construye Web Components reales con Lit v3

    ac-lit es un entorno de formación: un espacio para practicar arquitectura de componentes, testing en tres niveles, accesibilidad y un flujo de trabajo completo de FrontSpark a CI/CD.

    • Lit v3
    • Varios+ componentes
    • Testing (Unit · E2E · a11y)
    • Open Source (MIT)
    FrontSpark CLI

    $ npm install -g @ac-base/cli

    $ aclit component:create ac-button

    $ aclit component:serve

    # Componente listo en http://localhost:5173

    • Arquitectura sólida

      Mixins, tokens y patrones reutilizables.

    • Testing completo

      Unitarios, E2E y accesibilidad (a11y).

    • Flujo de trabajo real

      CLI, scaffolding y CI/CD con estándares.

    • Buenas prácticas

      Convenciones, estructura y documentación clara.
