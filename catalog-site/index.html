Comandos del CLI

terminal — aclit

$ npm install -g @ac-base/cli

$ aclit component:create ac-mi-componente

# Componente creado en ./ac-mi-componente

$ aclit component:serve

# levanta la demo con Vite en http://localhost:5173

$ aclit component:build

# compila el componente a ./dist

    Repositorio
    Lit v3

    Aprende a construir Web Components profesionales, paso a paso.

    ac-lit es un entorno de formación: un espacio para practicar arquitectura de componentes, testing en tres niveles, accesibilidad y un flujo de trabajo completo de CLI a CI/CD — con Lit v3 como base.

    Inicio rápido (CLI)

    Varios componentes de práctica · tests unitarios + E2E + a11y · CLI de scaffolding propio · Licencia MIT

    Objetivos de este entorno de formación

    Cada componente del catálogo es, a la vez, un ejemplo de producción y un ejercicio: así se ve una arquitectura de Web Components pensada para durar.

    • Arquitectura con Lit v3

      Mixins reutilizables, tokens de diseño y convenciones de naming consistentes en los 28 componentes del catálogo.

    • Testing en tres niveles

      Cada componente trae tests unitarios, E2E y de accesibilidad (axe-core) — practica a escribirlos y a leerlos.

    • Flujo de trabajo real

      Un CLI propio (aclit) para crear componentes, y un pipeline de CI/CD con Conventional Commits y versionado por Changesets.

    • Accesibilidad primero

      0 errores de axe-core en cada componente: la accesibilidad no es una fase final, es parte del diseño.

    • Buenas prácticas y estándares

      Convenciones de código, estructura de carpetas y revisión en cada PR, alineadas con la documentación oficial de Lit ↗.

    Tu primer ejercicio: crear un componente

    Instala el CLI, crea tu primer componente y levanta su demo — los mismos comandos que se usan para construir todo este catálogo.

    terminal — aclit

    $ npm install -g @ac-base/cli

    $ aclit component:create ac-mi-componente

    # Componente creado en ./ac-mi-componente

    $ aclit component:serve

    # levanta la demo con Vite en http://localhost:5173

    $ aclit help

    # lista todos los comandos disponibles
