    Bienvenido a ac-lit

    Un catálogo de Web Components listos para usar, con la demo real e interactiva de cada uno — elige un componente y pruébalo en los dos temas, en distintos tamaños de pantalla, con su código fuente a la vista.

    • Varios Web Components listos para usar, agrupados en un solo catálogo
    • Accesibilidad verificada con axe-core en cada componente
    • Modo claro y oscuro en cada demo, sin configuración adicional
    • Código fuente de cada caso de demo, a la vista
    terminal — aclit

    $ npm install -g @ac-base/cli

    $ aclit component:create ac-mi-componente

    # Componente creado en ./ac-mi-componente

    $ aclit component:serve

    # levanta la demo con Vite en http://localhost:5173

    $ aclit help

    # lista todos los comandos disponibles
